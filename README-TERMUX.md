# مبصر شیپورک — نسخه Termux
ربات مدیریت گروه خرید و فروش با دستورات متنی فارسی. دستورات مدیریتی با `!` یا `.` شروع می‌شوند.

## راه‌اندازی
`bash run-termux.sh`

## نمونه‌ها
`!لینک قفل` — `!لینک آزاد`
`!عکس قفل` — `!فوروارد حذف`
`!اضافه به لیست سفید` (ریپلای)
`!ریست` (ریپلای)
`!محدودیت تعداد پیام 5`
`!درهر 2 ساعت`
`!تکراری 3`
`!حداقل تعداد کلمات 3`
`!فیلتر کلمه`
`!اداجباری 5`
`!join @channel`
`!ربات قفل`
`!خاموشی اول از ساعت 23 تا 8`
`!فعال خوش`
`!فعال قوانین`
`!تذکر فعال`
`!اخطار خودکار فعال`
`!پاکسازی 100`
`!پیکربندی`

نکته: برای اجرای کامل اخراج/سایلنت/حذف، ربات باید در گروه مدیر و دارای دسترسی‌های لازم باشد. برخی محدودیت‌های تاریخچه و اعضای گروه به API تلگرام وابسته‌اند.
