مبصر بازارچه IR - نسخه ۲
حالت هوشمند فقط پست‌های مرتبط را نگه می‌دارد.
تبلیغات عادی شامل شماره، لینک، عکس، ویدئو، قیمت، هشتگ و ایموجی مجازند.
پیام‌های گفتگویی و نامرتبط با چند نشانه حذف می‌شوند.

نصب:
cd ~/downloads/mobsar
cp /مسیر/این/نسخه/bot.py .
export BOT_TOKEN='توکن'
python bot.py

قبل از جایگزینی، از mobsar.db پشتیبان بگیرید.


قانون جدید: ویدئو و ویدئوی دایره‌ای (Video Note) همیشه حذف می‌شوند.
