# 🤖 مبصر شیپورک

ربات مدیریت گروه تلگرام — بدون نیاز به VPS، روی Cloudflare Workers اجرا می‌شه و ۲۴ ساعته فعاله.

## ✅ پیش‌نیازها
1. یک حساب رایگان در [Cloudflare](https://dash.cloudflare.com/sign-up)
2. Node.js نصب‌شده روی کامپیوترتون (فقط برای یک‌بار دیپلوی کردن، نه برای اجرای دائمی)
3. یک توکن ربات تلگرام از [@BotFather](https://t.me/BotFather) — با دستور `/newbot` بسازیدش

## 🚀 مراحل نصب (فقط یک‌بار انجام می‌شه)

### ۱. نصب ابزار Wrangler
```bash
npm install -g wrangler
wrangler login
```
(یک صفحه‌ی مرورگر باز می‌شه، با حساب Cloudflare‌تون وارد بشید)

### ۲. ساخت دیتابیس D1
```bash
wrangler d1 create sheypoorak_db
```
خروجی این دستور یک `database_id` بهتون می‌ده — اونو کپی کنید و در فایل
`wrangler.toml` جایگزین `PUT_YOUR_DATABASE_ID_HERE` کنید.

### ۳. ساخت جدول‌های دیتابیس
```bash
wrangler d1 execute sheypoorak_db --remote --file=./schema.sql
```

### ۴. ثبت توکن ربات (به صورت امن)
```bash
wrangler secret put BOT_TOKEN
```
وقتی خواست، توکنی که از BotFather گرفتید رو پیست کنید و Enter بزنید.

### ۵. دیپلوی نهایی 🎉
```bash
wrangler deploy
```
بعد از اجرا، یک آدرس مثل این بهتون می‌ده:
```
https://sheypoorak-bot.YOUR_SUBDOMAIN.workers.dev
```
این آدرس رو کپی کنید.

### ۶. وصل کردن Webhook تلگرام به این آدرس
یک بار این لینک رو در مرورگر باز کنید (به‌جای مقادیر داخل `<>` مقدار واقعی بذارید):
```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=<ADDRESS_FROM_STEP_5>
```
اگر پیام `{"ok":true,...}` دیدید، یعنی ربات وصل شد ✅

## 🎉 تمام!
ربات الان ۲۴ ساعته فعاله. کافیه:
1. ربات رو به گروهتون اضافه کنید
2. ادمینش کنید (با دسترسی حذف پیام)
3. با دستور `!لینک قفل` یا `!عکس قفل` قفل‌ها رو فعال کنید

## 📋 دستورات موجود
| دستور | کاربرد |
|---|---|
| `/start` | معرفی ربات |
| `/id` | نمایش شناسه‌ی چت و کاربر |
| `/ثبت` | ثبت گروه در دیتابیس |
| `/قفلها` | نمایش لیست قفل‌های فعال |
| `!لینک قفل` / `!لینک آزاد` | مدیریت قفل لینک |
| `!عکس قفل` / `!عکس آزاد` | مدیریت قفل عکس |
| `!فوروارد قفل` / `!فوروارد آزاد` | مدیریت قفل فوروارد |
| (به همین ترتیب برای: فیلم، فایل، گیف، استیکر، شماره، لوکیشن، متن، نظرسنجی) |

## 🔧 اگر بعداً خواستید تغییری بدید
فقط کد رو ادیت کنید و دوباره اجرا کنید:
```bash
wrangler deploy
```
همین! نیازی به هیچ سرور یا کانفیگ اضافه نیست.

## ❓ اگر مشکلی پیش اومد
- **ربات جواب نمی‌ده:** چک کنید Webhook درست ست شده باشه (مرحله ۶)
- **ربات پیام رو حذف نمی‌کنه:** مطمئن شوید ربات در گروه، دسترسی "حذف پیام" داره
- **خطای دیتابیس:** چک کنید `database_id` در `wrangler.toml` درست پیست شده باشه

## حالت فقط آگهی
برای گروه تبلیغاتی، بعد از اضافه کردن ربات به‌عنوان مدیر با دسترسی حذف پیام، این دستور را توسط مدیر ارسال کنید:

`!فقط آگهی فعال`

در این حالت برای اعضای عادی فقط این دو نوع پست مجاز است:
- متن تبلیغاتی
- عکس همراه با متن تبلیغاتی

فقط عکس، چت، ریپلای، فوروارد، ویدئو، فایل، استیکر، گیف، نظرسنجی، پیام صوتی و سایر پیام‌های غیرآگهی حذف می‌شوند. پیام‌های ورود/خروج هم حذف و پیام خوش‌آمد غیرفعال می‌شود.

برای بازگشت به حالت عادی:

`!فقط آگهی غیرفعال`
